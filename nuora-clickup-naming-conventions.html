01

executive summary

Nuora in-house launches use one long, double-dash-delimited name as the shared identity spine across ClickUp, Facebook ad sets, Facebook ads, and tracking attribution.

batch identity

The first token is the batch id, usually B####. It is the strongest join key for onboarding, reporting, and reconciliation.

ad set identity

For Nuora in-house ClickUp pushes, the Facebook ad set name is the ClickUp task name, after runtime completion of any missing destination field.

ad identity

Each Facebook ad uses the ad set name plus a final variant token: --V1, --V2, --V3, or another numbered variant from the asset filename.

02

name grammar

Tokens are separated by a literal double dash. Do not split on single hyphens because names contain natural language, URLs, people names, and strategy labels.

ad set: B####--Product--AdType--Strategy--Problem/Desire--Awareness--Mechanism--Format--CS:Copy Strategist--V:Voice/Talent--Destination

ad: ad set name--V#

batch

B0405. Primary batch key. Use this as the most stable grouping key across platforms.

product

Nuora Feminine Gummies or Nuora Gut Capsule. Maps attribution back to product line.

ad type

Usually Video for current in-house launches. Other systems may use Static or Text.

strategy

Ideation, Iteration, or Imitation. Tells whether the batch is new, evolved, or modeled after a known structure.

problem or desire

Examples: Fishy odor, Bloating, Pooch/Weight, More oral sex. This is the market pain or outcome.

awareness

Unaware, Problem Aware, Solution Aware, or Product Aware. Useful for funnel-stage reporting.

mechanism + format

Mechanism examples: Biofilm, Parasites, Akkermansia + Biofilm. Format examples: Ai Avatar, Broll, Podcast, VSL style.

people + destination

CS: marks copy strategist. V: marks voice/talent. The final URL marks the landing destination used for that batch.

03

runtime flow

The naming convention is not just documentation. It is how the launch worker creates, stores, and reconciles Facebook objects.

source

clickup task

The operator-approved ClickUp task contains the canonical batch/task name plus fields for campaign, page, CTA, destination URL, copy, and Drive assets.

assets

variant extraction

Asset filenames are scanned for separated variant tokens such as --V1, -v2, _V3, or .V4.

facebook

ad set create

The ad set name is generated from the ClickUp task name. If the destination field fills a missing final segment, the live Meta name may include the completed URL.

facebook

ad create

One ad is created per variant. The ad name is the ad set name plus the final --V# suffix.

05

mobybots parsing contract

Recommended ingestion rules for a tracking attribution tool. Parse deterministically, keep the raw name, and avoid inventing meaning when a token is absent.

field source rule example
raw_adset_name facebook ad set name store exactly as received B0405--Nuora Feminine Gummies--...
raw_ad_name facebook ad name store exactly as received ...--https://mynuora.com/pages/feminine-gummies-3--V1
batch_id first token match ^B[0-9]{4,}$; keep uppercase B0405
variant ad name suffix or asset filename match separated V#; normalize to uppercase V1
product second token map exact token to product line Nuora Gut Capsule
ad_type third token normalize Video, Static, Text Video
strategy fourth token preserve label casing for reporting Iteration
awareness_stage awareness token detect known stage values, not fixed position only Solution Aware
destination_url last URL-looking token parse token beginning with http:// or https://; keep query params https://mynuora.com/pages/gut-capsule-2
06

operator rules

These rules keep ClickUp, Facebook, and attribution data aligned.

do

  • Use -- between major tokens.
  • Start every batch with a unique B#### id.
  • Put a separated variant token in every asset filename: --V1, -v2, _V3, or .V4.
  • Keep destination URLs complete in ClickUp fields before launch.
  • Use the raw Facebook names as the attribution source of truth after launch.

avoid

  • Do not split names on a single dash.
  • Do not infer quality or performance from naming tokens alone.
  • Do not treat missing URLs as proof that the ad had no destination; check the launch fields or live Meta row.
  • Do not overwrite raw names during ingestion. Normalize into separate parsed fields.
  • Do not rely only on ad status. A published ClickUp run can still have a later Meta review change.

important: Nuora also has an autonomous AI naming system that starts with AI####. That is a different architecture. This page documents the in-house ClickUp naming convention for approved ClickUp batches pushed to Facebook.
